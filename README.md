# Start Page

A minimal start page with clock, weather, and todo list.

## Setup as New Tab and Homepage

### Firefox
1. Install [New Tab Override](https://addons.mozilla.org/en-US/firefox/addon/new-tab-override/)
2. Go to extension settings → Set URL → point to `index.html`
3. Go to about:preferences → Home → New Windows and Tabs → set to "Custom Address" and enter the file path or a hosted URL

### Chrome / Chromium
1. Go to `chrome://extensions`
2. Enable **Developer mode** (top right)
3. Click **Pack extension**
4. Select this folder
5. Open new tab and homepage will automatically load this page
